## VEBLEN

BIST, küresel piyasalar ve TEFAS için masaüstü kantitatif komuta merkezi. Hesaplar yerel Rust çekirdeğinde çalışır; veriler bu bilgisayardan çıkmaz.

| Alan | Yaklaşım |
|---|---|
| Çekirdek | Rust: kantitatif motor, veri toplama, SQLite depolama |
| Arayüz | Tauri v2 masaüstü, sıfır web bağımlılığı |
| Lisans | Cloudflare Worker ile merkezi doğrulama, 1 anahtar = 1 cihaz |
| Güvenlik | Temiz kurulumda sıfır hesap, saat geri alma ve çevrimdışı kilidi, imzalı güncelleme |
| Dağıtım | Otomatik imzalı sürüm hattı, SHA-256 doğrulaması |
